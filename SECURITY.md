# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: go to the **Security** tab of this repo and click **Report a vulnerability** ([direct link](https://github.com/nicedreamzapp/dan-aquatic-ecology/security/advisories/new)). Only the maintainer sees the report.

Helpful details: what you found, which page it affects, how to reproduce it, and your browser and device.

I aim to reply within 3 days and to ship a fix or a clear plan within 30 days, depending on severity. You will be credited in the advisory unless you ask not to be.

## Supported versions

Fixes go into the latest version on `main`, which is what the live site on GitHub Pages serves.
